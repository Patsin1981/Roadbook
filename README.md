# Rally Roadbook — PWA สำหรับ Android

แอปวางเส้นทาง rally / TSD จากไฟล์ GPX ทำ roadbook (tulip, CP, อันตราย) และใช้นำทางในรถด้วย GPS มือถือ

## ไฟล์ในโฟลเดอร์

| ไฟล์ | หน้าที่ |
|---|---|
| index.html, app.css, app.js | หน้าแอป |
| core.js | คำนวณระยะ, project จุดลงเส้นทาง, หาจุดเลี้ยว, TSD, อ่าน/เขียน GPX |
| sw.js, manifest.webmanifest, icons/ | ทำให้ติดตั้งเป็นแอปและเปิดแบบ offline ได้ |
| vendor/leaflet, fonts/ | ไลบรารีแผนที่และฟอนต์ (เก็บในตัว ไม่ต้องโหลดจากเน็ต) |

## เอาขึ้น GitHub Pages (ฟรี ทำครั้งเดียว ต้องใช้คอม)

1. สมัคร/ล็อกอิน github.com แล้วกด **New repository** ตั้งชื่อเช่น `roadbook` เลือก **Public** กด Create
2. ในหน้า repo กด **Add file > Upload files** แล้วลาก *ทุกไฟล์และโฟลเดอร์ย่อย* ในโฟลเดอร์นี้ลงไป (ไม่ใช่ลากโฟลเดอร์ `roadbook-app` ทั้งก้อน ต้องให้ `index.html` อยู่ชั้นบนสุดของ repo) กด **Commit changes**
3. ไปที่ **Settings > Pages** ช่อง Source เลือก **Deploy from a branch**, Branch `main`, โฟลเดอร์ `/ (root)` กด Save
4. รอ 1–2 นาที จะได้ลิงก์ `https://<ชื่อ user>.github.io/roadbook/`

GPS ของ browser ใช้ได้เฉพาะเว็บที่เป็น https เท่านั้น ถ้าเปิดไฟล์ index.html ตรงๆ ในเครื่องจะใช้ GPS ไม่ได้

## ติดตั้งบน Android

1. เปิดลิงก์ด้วย Chrome
2. กดเมนู ⋮ > **ติดตั้งแอป** (หรือ Add to Home screen) หรือกดปุ่ม "ติดตั้งแอปลงเครื่อง" ในแท็บ ไฟล์
3. ตอนกด "เริ่ม GPS" ครั้งแรก ให้อนุญาตตำแหน่งแบบ **แม่นยำ (Precise)**
4. แนะนำ: ตั้งค่า Android > แอป > Chrome > แบตเตอรี่ > **ไม่จำกัด** เพื่อไม่ให้ระบบลดความถี่ GPS

## ขั้นตอนใช้งาน

**วางเส้นทาง**
1. แท็บ ไฟล์ > นำเข้า GPX (track แต่ละเส้น = 1 stage, waypoint ที่ห่างเส้นไม่เกิน 40 m ถูกดึงเป็นจุดให้ ถ้าชื่อมี START / CP / PC / TC / FINISH จะตั้งประเภทให้เอง)
2. แท็บ Stage > หาจุดเลี้ยวอัตโนมัติ > แตะวงกลมเหลืองบนแผนที่เพื่อเพิ่มทีละจุด หรือกด "+ จุด" แล้วแตะบนเส้นทางเอง
3. ในหน้าต่างแก้จุด: เลือกประเภท, ทิศ tulip, ทางแยกอื่น, คำสั่ง TH/EN, ปุ่ม −10/−1/+1/+10 m เลื่อนจุดไปตามเส้น ใช้คู่กับปุ่ม "ดาวเทียม" เพื่อวางตรงกลางแยกจริง
4. ลากหมุดบนแผนที่เพื่อย้ายจุดได้ ระบบจะดึงกลับลงบนเส้นทางและคำนวณระยะใหม่
5. ปรับระยะให้ตรง odometer: วิ่ง calibration zone แล้วกรอกในแท็บ Stage
6. ตั้งความเร็วเฉลี่ย TSD เป็นช่วงๆ ในแท็บ Stage
7. ส่งออก CSV (เปิดใน Excel ภาษาไทยไม่เพี้ยน) ไปทำ Road Book PDF ต่อ และบันทึก .json สำรอง

**นำทาง**
- เริ่ม GPS > ระยะคำนวณจากการ project ตำแหน่งลงเส้นทาง ไม่สะสมจาก GPS ดิบ จึงไม่ drift
- เตือนเสียง + สั่น ที่ 300 / 100 / 50 m ก่อนถึงจุด
- Sync จุด = ตั้งระยะให้ตรงกับจุด roadbook ที่ใกล้ที่สุด (กดตอนรถอยู่ที่จุดนั้นจริง)
- −10 m / +10 m ปรับระยะเอง, แตะช่อง "ช่วง km" เพื่อตั้งศูนย์
- เริ่ม TSD ตอนออกตัว ตัวเลข + คือช้ากว่าเป้า, − คือเร็วกว่าเป้า
- เพิ่มเติม: ซ่อนแผนที่ (ประหยัดแบต), จอกลางคืน, ส่งออกเส้นที่วิ่งจริงเป็น GPX

## ข้อควรรู้

- **แผนที่ offline**: แอปเก็บเฉพาะ tile ที่เคยเปิดดูแล้ว (สูงสุด ~6,000 ภาพ) ก่อนเข้าสนามที่ไม่มีสัญญาณ ให้เปิดแอปตอนมีเน็ตแล้วซูมไล่ดูทุก stage ทั้งโหมดแผนที่และดาวเทียมที่ระดับซูมที่จะใช้ ตัว track และจุดใช้ได้เสมอแม้ไม่มีพื้นหลัง
- **ข้อมูลเก็บในเครื่อง** ถ้าล้างข้อมูล Chrome หรือถอนแอปจะหาย ให้บันทึก .json ไว้เสมอ
- GPS ทำงานเฉพาะตอนแอปเปิดอยู่บนจอ (แอปขอให้จอไม่ดับเองระหว่างวิ่ง)
- **อัปเดตเวอร์ชัน**: แก้โค้ดแล้วเปลี่ยนค่า `VER` บรรทัดแรกใน sw.js แล้วอัปโหลดทับ แอปในมือถือจะขึ้น "มีเวอร์ชันใหม่"
